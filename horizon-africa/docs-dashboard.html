What is the Dashboard?
The Horizon Africa Dashboard is a web-based control panel that lets you manage leads, view WhatsApp conversations, send broadcast campaigns, schedule follow-up reminders, create message templates, and monitor integration health — all in one place.

Sending a Broadcast

Use the New Broadcast form to send a campaign:

  1. Enter a Campaign Name (e.g. "August Promotion")
  2. Select a Template from the dropdown (only Meta-approved templates can be sent)
  3. Optionally enter a Test Phone number to send a single test message
  4. If not testing, select a Group to send to all contacts in that group
  5. Click Send Broadcast

7. Templates

The Templates page is where you create and submit WhatsApp message templates for Meta approval. Templates must be approved by Meta before they can be used in broadcasts.

Creating a Template

  1. Click New Template
  2. Enter a Template Name in snake_case (e.g. horizon_followup_v2)
  3. Select a Language (English, Afrikaans, Zulu)
  4. Select a Category (Marketing, Utility, Authentication)
  5. Optionally add a Header and Footer
  6. Write the Body Text using {{1}}, {{2}} for variable placeholders
  7. If using variables, provide Body Example Values (comma-separated)
  8. Click Submit to Meta

Template Statuses

Each template shows one of three statuses:

  • Approved — Ready to use in broadcasts
  • Pending Review — Submitted to Meta, awaiting approval (auto-refreshes every 15 seconds)
  • Rejected — Rejected by Meta, cannot be used

9. Notifications

The bell icon in the top bar shows real-time notifications. A red badge with a number indicates unread items. Click the bell to view:

  • Hot Lead — A new lead has been scored as HOT
  • New Lead — A new lead has been captured
  • Escalation — A lead has been escalated to a human agent
  • Follow-Up Due — A follow-up reminder is due
